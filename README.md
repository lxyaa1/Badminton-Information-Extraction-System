# Badminton-Information-Extraction-System
项目架构如下：
Information Extraction System/
│
├── data/                        # 数据目录
│   ├── raw/                     # 原始羽毛球比赛新闻文本（txt文件，爬虫采集）
│   
│
├── results/                     # 结果目录
│   ├── extracted.json           # 信息抽取后的结构化数据
│   └── evaluation.json          # 人工评测结果
│
├── src/                         # 源代码
│  
│   ├── main.py                  # 命令行主入口，统一调度各模块
│   ├── crawler.py               # 爬虫模块，自动采集羽毛球新闻
│   ├── extractor_regex.py       # 信息抽取模块（正则/分词/启发式等）
│ 	├── evaluation.py            # 人工评测模块，支持交互式标注和统计
一、main.py
main.py 是命令行主入口，统一调度各模块。主要分为三个子命令：爬虫、信息抽取、人工评价。
1. 爬虫
功能：自动爬取羽毛球比赛新闻，保存为txt文本。
示例命令：
  python .\src\main.py crawl

  # 或自定义数量和保存目录

  python .\src\main.py crawl --num 100 --save_dir data/raw

2. 信息抽取
功能：对采集到的新闻文本批量抽取比赛名称、时间、地点、胜者、败者、比分等结构化信息，输出为JSON。
示例命令：
  python .\src\main.py extract

  # 或自定义输入输出路径

  python .\src\main.py extract --input_dir data/raw/ --output results/extracted.json

3. 人工评价
功能：对抽取结果进行人工标注（正确/错误/部分正确），并可统计准确率。
示例命令：
  python .\src\main.py evaluate

  # 只统计准确率

  python .\src\main.py evaluate --stats

二、crawler.py
1.爬虫设计思路
本爬虫主要实现从中羽在线（http://www.badmintoncn.com）赛事频道抓取羽毛球赛事新闻的功能。中羽在线网站有反爬机制，在未登录账号时访问会询问问题，所以我登录了自己的账号并使用cookie来爬取，并且只有标题中含有‘|’符号的新闻稿才有赛事信息
三、extractor_regex.py
1.信息抽取设计思路
本系统旨在从羽毛球赛事新闻文本中提取结构化比赛信息，实现从非结构化文本到结构化数据的转换。核心设计分为三个主要阶段：

​元数据抽取​：

从整篇新闻稿中提取全局赛事信息（比赛名称、日期、地点，胜者，败者，比分）
基于新闻标题和内容识别比赛层级信息

​局部分析​：

将文本切分为语义独立的句子单元
在单句粒度上识别比赛结果信息
识别比赛项目类型（男单/女单等）

​实体关系提取​：

识别比赛中的参赛选手/组合
抽取比分信息
建立"胜者-比分-败者"的三元组关系

​结果整合​：

将元数据与局部结果关联整合
批量处理多个文件并保存结构化数据
四、evaluation.py
1.评价系统设计思路
本人工评价系统旨在为羽毛球赛事信息抽取结果提供质量评估机制，核心设计思路如下：

​交互式评估流程​：

逐条展示抽取结果的关键字段
提供直观的三级评价标准（正确/部分正确/错误）
支持附加备注说明

​实时数据管理​：

每完成一条评价立即保存结果
防止程序中断导致数据丢失
保留原始数据的同时添加评估标签

​结果统计与分析​：

自动计算各类评价的比例
展示质量评估的量化指标

​便捷操作设计​：

简洁的指令输入（1/0/2/q）
批量评价与统计功能分离
